# Tic Tac Terminal

Final project for CS I (Catholic Institute of Technology, Summer 2025).

We started from a text-based terminal Tic-Tac-Toe (`original/text_based.py`) and rebuilt it with a Pygame GUI where you play by clicking the board.

## Contents
- `tic_tac_toe.py` Pygame Tic-Tac-Toe with three modes: two player, easy AI (random moves), hard AI (minimax)
- `ultimate_tic_tac_toe.py` Ultimate Tic-Tac-Toe, nine sub-boards inside one large grid
- `original/text_based.py` the pre-written terminal version we started from
- `docs/final_report.pdf` final report
- `xttt.png`, `ottt.png` piece sprites

## Run
```
pip install pygame
python tic_tac_toe.py
python ultimate_tic_tac_toe.py
```
Run from the repo root so the sprite images load.
